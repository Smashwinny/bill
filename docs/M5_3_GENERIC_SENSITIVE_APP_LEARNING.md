# M5.3 通用敏感应用学习与恢复边界

## 目标

不再为招商银行、其他银行或钱包逐个修改代码。敏感应用由本机注册表驱动：自动检测只提出建议，用户确认一次后即可复用同一套安全启动、暂停、提醒和恢复状态机。

## 身份与隐私

- 注册表保存在 `files/sensitive_app_registry.enc`，使用 Android Keystore AES/GCM 加密，并以临时文件、原子 rename、文件与目录 fsync 提交。
- 活动中的 session UUID、目标身份快照和状态机临时保存在本 App 私有 `SharedPreferences`，用于进程重建恢复；会话恢复确认后同步清除。它不是长期注册表，也不包含页面原文或 UsageEvents。
- 正式身份是 `Android 用户序号 + packageName + 签名证书 SHA-256`；名称仅用于显示，版本升级且签名不变时继续有效。
- 签名变化、应用替换、跨 Android 用户或卸载后重装为不同签名时 fail-closed，必须重新确认。
- 招商银行仅作为旧版本的一次迁移项；迁移后与其他敏感应用完全使用相同数据模型。
- 自动警告识别只在无障碍回调内存中匹配“共享/录制屏幕、无障碍风险”等强组合词，持久化只保存原因枚举，不保存页面原文、Activity 名称、截图或 UsageEvents 历史。
- 注册表冷启动、解密失败、包身份刚变化或已确认敏感应用被直接打开时，回调采用三态 fail-closed：不读取文本，并以包名哈希隔离记录 `A11Y_PROFILE_GUARD:<hash>` 覆盖缺口；该包身份确认完成或离开后只结束自己的区间，不会误关闭另一个包的缺口，历史仍等待权威账单补核。

## 两种学习入口

1. 自动建议：未知 App 暴露强安全警告时，生成一条待确认建议和私密通知；只有用户点击“确认学习”才进入正式注册表。
2. 用户教一次：主界面可选择最近使用的可启动 App，或从带图标、名称、包名的已安装 App 列表选择。列表和建议都携带选择当时的签名/用户快照；点击确认时身份若已变化，操作失败并要求重新选择，绝不只按包名确认。

## 安全启动事务

1. 重新读取已安装包的签名并与注册表比较。
2. 持久化目标身份快照、session UUID 和 `PREPARING`。
3. 排队 15 分钟人工恢复提醒。
4. 只从系统无障碍列表移除本 App 服务，读回并验证其他服务完全不变。
5. 同步清零心跳并打开 `A11Y_SERVICE` 覆盖缺口。
6. 确认可撤销通知已经实际发布。
7. CAS 为 `PAUSED`，再 CAS 为 `LAUNCHED`。
8. 启动仅属于已确认 package 的显式桌面入口。

任一步失败都不启动目标 App，并尝试恢复本服务。暂停缺口只有在新无障碍 Service 实例连接且耐久心跳成功后才关闭。
无障碍暂停/恢复缺口使用独立有序队列，不排在通知 outbox 重放之后。HyperOS 恢复已启用但未绑定的服务时，先移除并等待 500ms 让系统完成解绑，再基于最新服务列表加回本组件。失败只在 App 私有目录保存步骤名和异常类型，成功确认连接后删除，不记录包名或页面内容。

## 离开检测与恢复

- 正常安全启动返回：同一持久 session 已确认目标进入，且代理 Activity 重新 `onPostResume`，同时代理不在多窗口/PiP、目标包所有声明 Activity 均未声明 PiP 时自动恢复。
- 通知动作：携带唯一 session URI/generation，人工通知使用 session 独立 tag；旧通知、旧 Worker、旧前台服务 startId 不能停止或覆盖新会话。
- `PACKAGE_USAGE_STATS` 只在敏感会话期间由 `specialUse` 前台服务查询包级前后台事件；不保存其他 App 历史。
- 看到短信、相机、浏览器、系统权限、生物识别、桌面或其他 App 都不能证明银行流程结束，因此 UsageEvents 只把通知升级为“可能已离开，请确认”，绝不自动恢复。
- 使用情况权限被撤销、事件为空、查询失败、进程被杀或 15 分钟到期时保持暂停并提醒人工确认，不能猜测恢复。
- 用户在系统设置中强行停止自动账本后，Android 不允许任何组件自行恢复；必须重新打开应用。

## 资源边界

- 平时没有 UsageStats 轮询。
- 只有 `PAUSED/LAUNCHED` 敏感会话启动 1 秒级前台观察；进入恢复或会话结束立即停止。
- 服务不使用 MediaProjection、截图、节点树或屏幕内容权限，因此不属于录屏/共享屏幕实现。

## 验收重点

- 同名不同包、同包不同签名不能自动合并。
- 关键词只产生建议，不能自动暂停或启动。
- 目标未进入、UsageEvents 重复/乱序/空、权限撤销均不能触发恢复。
- 目标→生物识别/权限/相机/文件/浏览器/短信→目标期间始终保持暂停。
- 同一 session 的代理正常返回只恢复一次；旧 session 通知无副作用。
- 其他无障碍服务在暂停/恢复前后保持完全一致。
