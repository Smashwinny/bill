# 手动账本分类树真机验收

适用版本：`0.6.4-convergent-category-merge`（versionCode 13）及后续版本。

本清单验证分类树、历史账单联动、分析图表和同步按钮。覆盖安装不得卸载应用或清除数据，验收前先备份当前账本。

## 1. 安装与数据保护

```bash
adb install -r manual/build/outputs/apk/debug/manual-debug.apk
```

预期：安装成功，原有账单数量、总收入和总支出不变；原先直接绑定一级分类的账单显示为“原分类 › 未细分”，没有新增或丢失账单。

## 2. 分类拖动与历史账单联动

1. 新建两笔测试支出，分别归入两个不同的最下级分类，记录金额和分类路径。
2. 进入“设置 → 分类管理 · 长按拖动”。
3. 长按其中一个分类的拖动图标，将它拖到另一个分类行上。
4. 返回流水页搜索两笔测试账单。

预期：被拖分类成为目标分类的子分类；原账单 ID、金额、日期和备注不变，分类路径立即变为新层级；账单始终绑定最下级分类。

## 3. 同名合并

1. 准备两个位于不同父节点下的同名分类，并各放入一笔测试账单。
2. 将一个同名分类拖到另一个同名分类上。

预期：出现“合并同名分类？”确认框；取消时数据不变；再次操作并确认后只保留目标分类，两笔账单均存在且归入合并后的最下级分类，没有重复账单。

## 4. 删除与无分类兜底

1. 点击包含测试账单的非系统分类旁删除图标。
2. 检查确认框，再先取消一次。
3. 重新删除并确认。

预期：确认框显示受影响账单总数，并列出日期、金额、原分类及备注摘要；取消不改变数据；确认后分类及子分类消失，受影响账单完整转入“无分类”；刷新和重启后被删分类不会恢复。

## 5. 点击账单改分类

1. 在“流水”页点击账单卡片空白区域，而不是“改分类”按钮。
2. 选择另一个最下级分类。

预期：弹出“更改账单分类”；只提供叶子分类；选择后账单路径立即更新，其他字段不变。

## 6. 分析页

切换到包含测试账单的月份，检查每日消费日历、每日消费柱状图和分类占比饼图。

预期：账单日期对应的日历金额和柱高正确；饼图及下方分类金额之和等于该月支出；切换上月和返回本月均有响应。

## 7. 同步按钮

在已配置专用 Tunnel 的前提下点击“设置 → 立即同步”。

预期：页面立即显示“正在同步”；成功后显示“同步完成”且待同步数量归零；断网时本地账单仍可保存，界面保留待同步数量并显示失败原因，恢复网络后再次同步不会产生重复账单。

## 8. 自动化数据库测试

连接手机后执行：

```bash
./gradlew :manual:connectedDebugAndroidTest
```

预期：Room 1→2 迁移、导入去重、叶子绑定、拖动、同名合并、删除兜底和同步事件数量断言全部通过。
